# CR-001 — Изменение ограничения количества записей к психологу

## Описание изменения

**Идентификатор:** CR-001.

**Дата:** 24.11.2026.

**Проект:** Psychologist_nearby.

**Статус:** предложено, ожидает согласования.

**Исходное требование:** максимальное количество подтверждённых записей к одному психологу составляет 4 записи в день.

**Новое требование:** максимальное количество подтверждённых записей к одному психологу составляет 5 записей в день.

**Обоснование:** повышение доступности психологических консультаций.

## Критерии приёмки

- При наличии четырёх подтверждённых записей пятая запись разрешается при соблюдении остальных условий.
- При наличии пяти подтверждённых записей шестая запись отклоняется.
- Пользователь получает сообщение об ограничении в 5 записей в день.
- Остальные ограничения записи сохраняются без изменений.
