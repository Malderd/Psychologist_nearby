# Psychologist_nearby 

Веб-приложение специалиста-психолога, на котором можно пройти тестирование и затем записаться на прием. Приложение разработанно на платформе **.NET 8** с использованием **C#**, **Blazor** и базы данных **MySQL**.

## О проекте

**Psychologist_nearby** — веб-приложение, предназначенное для прохождения тестирования с последующей записью на курсы.

Основная идея проекта — предоставить пользователю возможность записаться на прием к специалисту, просмотреть информацию о специалисте и использовать функциональность приложения через удобный веб-интерфейс.

Проект разработан с использованием современной технологии **Blazor**, позволяющей создавать интерактивные веб-приложения на языке C#.

## Основные компоненты

### Пользовательский интерфейс

Интерфейс приложения реализован с использованием **Blazor**.

Blazor позволяет создавать интерактивные компоненты веб-приложения с использованием C#, что позволяет использовать один основной язык как для логики приложения, так и для серверной части.

Интерфейс включает страницы и компоненты для работы с функциональностью сервиса.

### Серверная логика

Основная логика приложения реализуется на **C#** с использованием возможностей **.NET 8**.

В серверной части выполняются:

* обработка пользовательских действий;
* работа с моделями данных;
* взаимодействие с базой данных;
* выполнение бизнес-логики;
* обработка ошибок;
* предоставление данных компонентам интерфейса.

### База данных

Для хранения информации используется **MySQL**.

База данных предназначена для хранения данных, необходимых для работы приложения, например:

* информации о психологе;
* информации о пользователях;
* данных профилей;
* дополнительных данных, связанных с работой приложения.

Структура базы данных, создание таблиц и настройка подключения выполняются Даниэлой Паэгле.

---

## Работа с базой данных

Приложение взаимодействует с MySQL через настроенное подключение к базе данных.

Общий принцип работы:

```text
Пользователь
     │
     ▼
Blazor-интерфейс
     │
     ▼
C# / .NET 8
     │
     ▼
Сервисы приложения
     │
     ▼
MySQL
```

При выполнении операции, требующей получения или изменения данных, приложение обращается к соответствующим компонентам работы с базой данных.
